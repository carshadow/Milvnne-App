🛍️ MILVNNE Studios – Full Stack E-Commerce App

MILVNNE Studios is a modern full-stack e-commerce web app built with React, Tailwind CSS, Framer Motion, Node.js, Express, MongoDB, Stripe, and Cloudinary.
It includes a full Admin Dashboard, secure checkout, inventory management, and email notifications for both clients and admin.

🌐 Live Site: brand-app.fly.dev

⚙️ Backend API: clothing-backend.fly.dev

🧠 Tech Stack

Frontend:
React • React Router • Tailwind CSS • Framer Motion • React Icons

Backend:
Node.js • Express • MongoDB (Mongoose) • Stripe • Cloudinary • Multer • Nodemailer • JWT • Zod

Deployment:
Fly.io (frontend & backend) • Namecheap (domain)

⚙️ Core Features

🛒 Product Catalog with search, categories, hover effects & responsive layout

🎨 Admin Dashboard for managing products, categories, and orders

💳 Stripe Checkout integration with Webhook automation

☁️ Cloudinary Uploads for product & category images (desktop & mobile)

💸 Discount System with automatic price recalculation

📦 Inventory Control (size-based or general stock)

📧 Email Notifications (Nodemailer):

Client → purchase confirmation with product images

Admin → order summary with product photos & dashboard link

👤 User Accounts with JWT Auth, profile editing & order tracking

🔐 Forgot / Reset Password via secure email token

🪶 Smooth Animations and UI transitions with Framer Motion

🚀 Fully deployed and production-ready on Fly.io

🧩 How It Works

Users browse products, add to cart, and checkout with Stripe.

Stripe Webhook confirms payment and creates an order in MongoDB.

Stock updates automatically per product or size.

Client receives confirmation email with details and images.

Admin receives summary email instantly with photos and total.

Orders are managed and tracked through the Admin Dashboard.
